Help & System Info

1. การจัดรูปแบบไฟล์นำเข้า (Excel/CSV/TXT)

ไฟล์ตรวจสอบแบบ Batch จะต้องมีคอลัมน์แรกสุดหรือมีหัวตารางระบุหมายเลขโทรศัพท์ 10 หลัก (เช่น 0812345678 หรือ 6681234567) ระบบจะดึงแถวแรกและคัดกรองข้อมูลเฉพาะตัวเลขเพื่อส่งยิงทดสอบ API ต่อไป

2. สถานะการทำงานของแต่ละระบบปลายทาง

  • AVAILABLE: หมายเลขว่าง ยังไม่มีข้อมูลการลงทะเบียนหรือเปิดใช้งานในระบบนั้นๆ พร้อมใช้งาน
  • ACTIVE: หมายเลขถูกจองหรือลงทะเบียนในระบบเรียบร้อยแล้ว (ไม่สามารถวนจำหน่ายซ้ำได้)
  • ERROR: ไม่สามารถดึงข้อมูลได้เนื่องจาก API ปลายทางมีข้อจำกัดหรือขัดข้องทางเครือข่าย

3. รายละเอียดการเชื่อมต่อ (Intranet Connection)

การเช็คข้อมูลยิงผ่าน REST API ที่ทำงานบน JBoss EAP 7.2 ภายใต้ระบบเครือข่ายความปลอดภัยอินทราเน็ต ในการตรวจสอบเบอร์แบบข้ามระบบ (Cross-System Verification) สำหรับฝ่ายจัดการเลขหมาย
